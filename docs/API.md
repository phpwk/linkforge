# LinkForge — API Reference

Base URL: `https://api.linkforge.example` (prod) / `https://api.dev.linkforge.example` (dev).

**Authentication: none.** Every endpoint below is unauthenticated and
unrated-limited. This is a stated non-goal (see PRD §3), not an oversight —
do not point this API at a deployment holding data you care about being
public.

All request/response bodies are JSON except the redirect endpoint, which
returns no body.

---

### `POST /api/links`

Create a short link.

**Request body:**
```json
{ "url": "https://example.com/some/very/long/path" }
```

**Responses:**

| Status | Body | When |
|---|---|---|
| 201 | `{ "code": "aB3xY9z", "originalUrl": "...", "createdAt": "2026-08-11T07:29:00.000Z" }` | Created |
| 400 | `{ "error": "url must be an absolute http(s) URL" }` | Missing or non-http(s) `url` |
| 503 | `{ "error": "could not allocate a unique code, try again" }` | 5 collision retries exhausted (practically never — see ADR context in `links.js`) |

`code` is a 7-character base62 string generated by `nanoid`; collisions are
detected via a database unique constraint and retried automatically —
callers never need to retry themselves for this reason.

---

### `GET /api/links`

List recent links, most recent first.

**Query params:** `limit` (optional, integer, default 20, capped at 100).

**Response `200`:**
```json
[
  { "code": "aB3xY9z", "originalUrl": "https://example.com", "clicks": 12, "createdAt": "2026-08-11T07:29:00.000Z" }
]
```

---

### `GET /api/links/:code/stats`

Single link detail.

**Responses:**

| Status | Body |
|---|---|
| 200 | `{ "code": "...", "originalUrl": "...", "clicks": 12, "createdAt": "..." }` |
| 404 | `{ "error": "not found" }` |

---

### `GET /:code`

The short link itself. Redirects and increments the click counter in the
same database statement (atomic — no lost updates under concurrent clicks).

**Responses:**

| Status | Headers / Body |
|---|---|
| 302 | `Location: <originalUrl>` |
| 404 | `{ "error": "not found" }` |

---

### `GET /healthz`

Liveness probe. Always returns `200 { "status": "ok" }` if the process is
running — deliberately does not check the database, so a slow database
never causes Kubernetes to kill and restart a healthy pod (see HLD §2.2).

### `GET /readyz`

Readiness probe. Returns `200 { "status": "ready" }` if a `SELECT 1` against
Postgres succeeds, `503 { "status": "not ready", "error": "<message>" }`
otherwise. This is what gates whether the Service routes traffic to a pod.

### `GET /metrics`

Prometheus text-exposition format. Not meant for humans — see
[HLD.md §2.4](./HLD.md#24-observability-cross-cutting) for what's exposed
and `deploy/monitoring/grafana-dashboard.json` for the dashboard built
against it.

---

## Error shape

Every error response follows the same shape: `{ "error": "<message>" }`.
There is no error code/type field beyond the HTTP status — if a caller needs
to distinguish error causes programmatically beyond status code, that's a
gap to close before this API has external consumers.
